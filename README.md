# 担心 Claude 账号被封控，如何导出 Claude 数据，并丝滑切换到 GPT

最近如果你遇到 Claude 风控、限制登录，或者本身就担心账号哪天突然出问题，建议提前做一件事：
**把自己的数据先导出来。**

>[点击查看文章：《Claude 防封经验（IP、注册、充值和使用习惯）一次说清
》](https://clawdo.com/2026/08/Claude-Account-Safety-Guide-IP-Registration-Payment-and-Usage/)

别等账号彻底进不去了，再想起聊天记录、项目资料和长期上下文还都在 Claude 里面。

如果你已经准备逐步切换到 ChatGPT，也可以提前把 GPT 账号和会员准备好。

国内用户如果不方便使用海外支付，可以通过：

**ChatGPT Plus / Pro 升级：cnmGPT.com**

后面把 Claude 的历史数据整理好以后，就可以直接迁移到 GPT 继续使用。

这篇文章主要讲两件事：
**Claude 数据怎么备份，以及备份以后怎么把长期上下文迁移到 GPT。**


## 1. 如何把你的 Claude 数据导出来

进入 Claude 设置，选择 privacy 点击导出数据。

![Settings → Privacy → Export data](https://files.mdnice.com/user/166515/07c374b0-7f7c-42a9-bbef-2c53d04e805a.png)


可以选择全部数据，也可以按日期筛选。

![选择导出数据量](https://files.mdnice.com/user/166515/345bd9bd-0fe4-48ac-b853-a94b4505f20a.png)


提交后，Claude 会通过邮箱发送下载链接，下载到本地保存即可。

![收到官方邮件后下载](https://files.mdnice.com/user/166515/f367c783-c783-4388-bfc0-6d8456e5e83a.png)


如果你的 Claude 目前还能正常登录，建议现在就做一次备份。

**尤其是长期使用 Claude、里面有大量项目和重要对话的用户。**

将下载下来的文件使用文本编辑打开，你会得到三条下载链接，复制并在谷歌浏览器打开。

![](https://files.mdnice.com/user/166515/9f938538-9cac-4b10-8dfc-93fe5acddc5e.png)

Claude 会立即下载zip文件，你只需要点击解压就能得到包含对话内容的 json 文件。

![解压后的两个文件和对话内容的 json 文件](https://files.mdnice.com/user/166515/4db3ef4b-f6d3-4fd8-97e2-cc16a456676e.png)

**到这里，你的 Claude 数据已经有了一份本地备份。**


## 2. 导出后，怎么迁移到 GPT？

不需要把几百条聊天一条条搬过去。

更实用的方法，是把 Claude 历史数据整理成一份长期上下文文件。

新建一个 Claude/GPT 对话 将下方的提示词丢给  Claude/GPT 并附带刚刚的 json 文件：
```
我准备从 Claude 切换到 ChatGPT。请把我上传的 Claude 对话导出数据、你当前可访问的关于我的记忆信息，以及可检索到的相关历史聊天内容，整理成一个可下载的 Markdown 文件。

文件名：`Claude-to-ChatGPT.md`
格式：UTF-8 Markdown。

## 1. 检查数据源

检查所有上传附件，区分：

* 实际对话记录
* 项目/账户元数据
* 压缩包或其他可提取档案
* `manifest-*.json` 等仅包含下载链接的索引文件

`manifest-*.json` 不算实际对话内容，也不要自动访问其中的一次性下载链接。

如有压缩包，请尝试提取并读取实际数据。若对话数据缺失、损坏或无法读取，请明确说明，并将最终结果标记为“信息不完整”。

## 2. 提取可用的个人上下文

除上传文件外，请整理当前可访问的：

* 已存储的记忆信息
* 我的长期偏好和回复规则
* 相关历史聊天中的有效信息

重点包括：

* 身份、背景、角色
* 业务、产品、客户、服务
* 长期目标、优先事项、限制
* 写作风格、格式要求、禁用表达
* 常用工具和工作流程
* 正在进行的项目、决策、状态、下一步
* 重要名称、日期、数字、术语、链接
* 我明确确认或修改过的规则

请区分信息来源：

* “记忆中的内容”
* “上传的 Claude 对话”
* “此前 ChatGPT 聊天记录”

无法访问的来源请明确说明，不要猜测。

## 3. 分析与合并

将所有有效信息合并、去重，并：

* 以最新修改为准
* 标记冲突和不确定信息
* 对价格、额度、项目状态、日期等时效性内容注明对应时间
* 不把旧信息默认视为仍然有效
* 不把你过去给出的建议当成我已经接受的决定
* 不把我偶尔提出的问题自动当成长期偏好
* 排除密码、API Key、Token、私有下载链接等敏感信息

## 4. 输出结构

请按以下结构生成：

# 上下文信息来自 Claude

## 相关背景信息

对未来协作最重要的个人和业务背景。

## 回复指南/说明

用第一人称撰写，不超过 1,500 个字符，可直接复制到 ChatGPT 自定义指令。

## 永恒的回忆

按主题整理长期有效的背景、偏好、职责和明确修正。

## 目标与工作流程

我的工作重点、常用流程和协作方式。

## 项目与决策

每个项目分别写清：
目的、最新状态、已确认决策、限制、未解决问题、下一步。

## 详细参考资料

重要日期、数字、名称、链接、历史背景和已确认示例。

## 冲突与未知因素

列出冲突、可能过期、缺失或无法验证的信息。

## 源数据覆盖率

说明：

* 处理了哪些上传文件
* 哪些文件未读取或仅部分读取
* 实际读取到多少对话及时间范围
* 是否使用了记忆信息
* 是否检索到此前聊天记录
* 有哪些信息缺失

重要事实尽量附简短来源，例如：
“Claude 对话：标题，日期”
或
“记忆中的内容”。

不要复制完整聊天记录，只保留详细、实用的总结。

## 5. 最终检查

交付前确认：

* 上传历史数据和可用记忆都已尽可能利用
* 明确偏好和修正均被保留
* 建议与已确认决策没有混淆
* 时效性信息都有日期
* 所有处理缺口均已披露

最后返回：

1. 可下载的 `Claude-to-ChatGPT.md`
2. 一段简短说明，说明本次数据覆盖情况和是否完整

除非已经验证，否则不要声称“全部历史已完整处理”，也不要声称这些内容会自动或永久保存到 ChatGPT。
```

最后整理成：`Claude-to-ChatGPT.md`

它的作用不是保存所有聊天原文，而是把真正值得迁移的内容提炼出来。

这样文件会更小，也适合作为 GPT 后续长期使用的上下文。

![点击下载 Claude-to-ChatGPT.md](https://files.mdnice.com/user/166515/1e437812-6996-4970-af32-7b788add9625.png)

进入 GPT 资料库，上传该文件。

![资料库>新建>上传](https://files.mdnice.com/user/166515/10fba2f7-0917-4276-a3ca-b0487338234e.png)


新建对话，添加 Claude-to-ChatGPT.md 文件，并输入提示词发给 GPT ：
```
此文件包含从Claude传输的我的上下文。
阅读并记住这些持久的事实、偏好、目标和重复的工作流程，它们将在未来的对话中帮助你。
保留我现有的准确记忆。在替换之前标记冲突信息。将日期项目状态和指标视为历史数据，除非确认为当前状态。
```
这样做以后，GPT 就能更快理解你过去在 Claude 中长期积累的使用习惯和项目背景。

![选择刚刚添加到资料库的 Claude-to-ChatGPT.md 文件](https://files.mdnice.com/user/166515/51c7876a-bcc2-4079-95a9-a4c35c8a7a07.png)

完成之后你就会发现，你的 GPT 记忆信息已更新，你就可以在 GPT 中拥有 Claude 的记忆了。

![记忆信息已更新](https://files.mdnice.com/user/166515/dc475e72-43ad-477b-89fc-cb2a473d518c.png)




## 3. 如果已经被封控怎么办？

如果账号**还能进入设置页面**，第一时间尝试导出数据。

如果已经完全无法登录，那么正常的数据导出就会比较困难。

所以这篇文章其实不只是写给已经被封控的人。

更重要的是提醒那些：
**Claude 现在还能正常用，但担心以后被风控的人。**

提前备份一次，成本很低。

真出问题的时候，会省很多麻烦。


## 4. 最后

最稳妥的做法其实很简单：

**Claude 正常使用时提前导出 → 本地备份 → 整理长期上下文 → 需要时迁移到 GPT。**

账号和模型都可能会变。
但自己的项目资料、聊天记录和使用习惯，最好一直掌握在自己手里。
